# LogDig launch-media design

This system applies only to `docs/launch/artboard.html` and exported launch media. It does not replace the CLI's terminal conventions or prescribe an Obsidian theme.

## Direction contract

**Thesis:** Recover Pi history into a readable journal. Show actual processing beside its actual output instead of a generic feature grid.

**Own-world:** Mint `#d7efdf` workspace, deep-green `#172f30` ink, `#152b2b` terminal and off-white `#fafbf7` Markdown. Flat, rectangular working surfaces; no gradients, ornamental icons, or invented dashboard chrome.

**Story:** Recognize the benefit, see four independent sessions at work, open linked detail, then try the safe preview. Disclosure stays visible throughout.

**First viewport:** Fixed 1600 × 1000. A large two-line promise above a 790-pixel terminal and 650-pixel journal, separated by 32 pixels. Repository URL at top right. Real Markdown content, personal note and project grouping carry the proof.

**Form:** User-pinned actual-output/code-first composition. Seed `c4abba8f` does not override that explicit direction. The signature motion is recorded progress completing out of order, followed by the linked summary. A thin elapsed rail ensures browser recording includes otherwise static dwell time.

**Finish:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Built system

- Display: bundled Lato Bold, 76px, 1.03 line height, -0.035em tracking.
- Journal body: bundled Lato Regular, 20px, 1.4 line height.
- Terminal: DejaVu Sans Mono or monospace, 14px, 1.85 line height.
- Muted ink: `#506564`; links and elapsed rail: `#24654b`.
- Outer safe area: 64px horizontally, 56px at top. No external font or image requests.
- Export dimensions are fixed. Consumers scale the complete frame; this is not a responsive website.
- Media is silent, with no flashing or animated decorative fields. Static PNG is available beside GIF and MP4.
